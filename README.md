# 🎓 EduNova Global Academy — School ERP & CMS

Monorepo for the EduNova platform: a Django/DRF backend (Render) + React/Vite
frontend (Vercel) + Supabase PostgreSQL.

```
EDunova-CR/
├── backend/    Django + DRF (apps, portal, config, migrations, tests, Docker)
├── frontend/   React 18 + Vite + Tailwind (all portals + public site)
├── docs/       All documentation (setup, audit workflow, reports, DB blueprint)
├── .github/    CI workflow
```

**Documentation lives in [`docs/`](docs/README.md)** — start with
[`docs/SETUP.md`](docs/SETUP.md) (how to run it) and
[`docs/PRODUCTION_READINESS.md`](docs/PRODUCTION_READINESS.md) (go-live checklist).
